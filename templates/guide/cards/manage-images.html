🖼️ Managing Story Images

Add, describe, replace, or remove an image

A story can include an uploaded image. You can manage that image from the story-editing page without deleting the story itself.

Basic steps

  1. Log in and click Admin.
  2. Click Stories.
  3. Select edit beside your story.
  4. Select Edit alt text to improve the image description.
  5. Select Delete image to remove the image from the story.

Replacing an image

Delete the current image, return to the story editor, and upload the replacement. Save the story when the new image is ready.

What happens

Editing alt text changes the image description. Deleting an image removes the image but leaves the story and its text in place.

Important

Saving changes to a public story makes it private again. Select Request Review when the revised story and replacement image are ready to be published.

Why this matters

Clear images and useful alt text make stories more engaging and more accessible to people using screen readers.
